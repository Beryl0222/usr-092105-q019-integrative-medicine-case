# 融合医学临床教学案

本项目实现“融合医学临床教学案”系统：把脱敏病例及教学同意、症状和检查事实、证候观察、问题表述、药物相互作用、候选机制、学生各版决策、跨学科意见、模拟结果、临床回顾与能力反馈**分层保存**在四类聚合事件流中，供课程间同步与教学分析使用。

## 分层结构

| 聚合流 | 承载内容 |
| --- | --- |
| `teaching_case` | 脱敏病例、教学同意（scope/deidentified/valid_until）、授权到期 |
| `clinical_observation` | 症状与检查事实、证候观察、问题表述、药物相互作用、候选机制（`kind` 区分） |
| `student_plan` | 学生各版决策（`revision` 递增，含合并/保留/排除及依据）、模拟结果 |
| `faculty_feedback` | 跨学科意见、临床回顾、能力反馈；教师分歧追加并存，互不覆盖 |

## 固化的领域规则（`src/rules.py`）

- **体系中立**：方案与取舍不得携带 `system_priority` 等体系优先字段，系统不替师生裁定医学体系优先级。
- **相关性 ≠ 疗效**：候选机制的表述强度受证据等级约束——相关性证据最高只能表述为“关联”，疗效表述需要临床试验或系统综述证据；候选机制永远保持 `candidate` 状态。
- **取舍必有依据**：每次合并、保留或排除都必须给出文字说明，并引用至少一条事实、相互作用、候选机制或教师意见，且引用必须真实存在。

## 授权与保留

- 授权有效期内，课程经 `grant_access` 获得访问；**授权到期后停止新课程访问**，病例内容同时冻结。
- 已形成的成绩证据（各版方案、教师意见、能力反馈）按规则保留：到期前已获授权的课程仍可以 `purpose="grade_evidence"` 查阅。
- 同意延期（`update_consent`）后可重新开放。

## 修订并排视图（`src/revision.py`）

`compare_revisions` 把某次修订的四条线索并排呈现，每条都带来路（事件标识与时间）：新增事实、冲突识别、治疗取舍（含依据与引用）、教师分歧（多学科并存）。`render_side_by_side` 输出文本对照表。

## 课程负责人分析（`src/analytics.py`）

用真实决策变化判断教学是否仍只是把两套术语拼在一起：

- **共同解释率**：问题表述同时连接西医与中医观察的比例；
- **取舍有据率**：取舍引用事实层记录（而非空泛术语或仅引用意见）的比例；
- **拼贴指数**：上述两者均值的补，按方案版本展开成趋势；`course_report` 标出未改进且拼贴指数高的方案。

## 课程间同步（`src/sync.py`）

`export_events` 导出符合公共信封的事件；`import_events` 先校验信封，再按 `event_id` 幂等落库——来源系统重试时沿用原事件标识即可安全重放，版本冲突逐条报告。

## 目录

- `contracts/domain.schema.json`：事件信封与本领域允许的聚合、事件类型。
- `src/events.py`：事件信封与仅追加存储（JSONL，幂等）。
- `src/rules.py` / `src/services.py`：领域规则与分层应用服务。
- `src/revision.py` / `src/analytics.py` / `src/sync.py`：修订视图、课程分析、同步。
- `data/sample.json`：单条信封样例；`data/sample_scenario.jsonl`：完整中文教学场景（13 条事件）。
- `tests/`：契约、规则、授权、修订视图、同步与课程分析测试。
